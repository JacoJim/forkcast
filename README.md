# Forkcast

Our family's meal planner: a planned month of dinners and a weekly grocery list.

**Open it:** https://jacojim.github.io/forkcast/

**On an iPhone:** open the link in Safari, tap the Share button, then **Add to Home Screen**. It then opens like an app and works with no signal. Your meals are saved on your phone only.

**On Android:** ask for the Forkcast app file (APK) instead.

This repo holds only the built app. It's published automatically.
